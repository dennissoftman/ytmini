# ytmini

Minimal desktop YouTube client (Rust, egui + libmpv) for macOS and Windows.

Before any work, read [CONTRIBUTING.md](CONTRIBUTING.md): privacy rules for
the session cookies, language vs region, translations, Windows process rules,
commit style (release-please) and how to test without touching the user's
watch history. If `CLAUDE.local.md` exists, it holds the maintainer's own
routine and takes precedence for that machine.
