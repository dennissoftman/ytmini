# Security

ytmini holds a copy of your YouTube session, so anything that could leak it
or run code on your machine is a security issue: cookies reaching a host
other than YouTube or Google sign-in, cookies or stream links in logs, links
or video data that end up executed, tampered yt-dlp or deno downloads.

Please report these privately through
[GitHub's security advisories](https://github.com/dennissoftman/ytmini/security/advisories/new)
rather than a public issue. Fixes ship in the next release; only the latest
release is supported.
